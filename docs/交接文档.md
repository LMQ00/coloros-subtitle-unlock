# 交接文档（入口页）

> 最后同步 2026-09-28
> 本页只做**路由**：事实的唯一出处是 `docs/` 下的各类型文档与 `../AGENTS.md`，此处不复述细节。

## 一句话

ColorOS 16 逆向项目：用**一个 LSPosed 模块**解除系统 AI 音频功能的客户端限制 ——
「AI 语音摘记」字幕每月 120 分钟限制、以及「声音分轨」的应用白名单限制。

现状：**两个功能均已在真机验证通过**；模块 v1.10 已装机，开机自动生效。
（状态判据与验证步骤见 `testing.md`；仓库/产物见 `README.md`）

## 最短上手路径

1. 读 `README.md` 建立全貌（2 个功能 + 作用域 + 产物）。
2. 按 `testing.md` 的「真机验证」步骤跑一遍探针，确认设备当前状态。
3. 要改代码 → 先读 `../AGENTS.md` 的硬性约束，再读对应主题文档（字幕 `01`+`02`；分轨 `04`+`05`）。
4. 改完 push `main`，GitHub Actions 自动编译；产物用 `gh run download` 取回（见 `README.md`）。
5. 装机与作用域勾选见 `testing.md`「装机与作用域」。
